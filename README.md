# 🏰 Simple Dungeon

Это простая текстовая игра в консольном формате.

Главная цель проекта — развивать и усложнять игру по мере нашего продвижения в изучении программирования и принципов разработки. Проект будет обновляться, обрастать новыми механиками и архитектурными решениями.

## 🎮 О игре
Вы оказываетесь в таинственном подземелье. Каждый шаг — это выбор, который определяет вашу судьбу. Перед вами двери, за которыми скрываются случайные или заранее заготовленные события: ловушки, сундуки с сокровищами или переход на следующий этаж.

### Что будет на релизе? (Версия 1.0):
* Линейный игровой процесс.
* Выбор действий через консольный ввод (например, нажать `1` или `2` для выбора двери).
* Базовая текстовая визуализация происходящего.
